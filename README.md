# N-Queen Visualizer ♛

An interactive web-based visualization of the N-Queens problem using backtracking.

## 🚀 Features
- Dynamic board size (2–8)
- Step-by-step visualization
- Speed control
- Solution counter
- Clean UI with animations

## 🧠 Algorithm
Backtracking approach:
- Place queens column-wise.
- Validate row, column, diagonal.
- Backtrack on conflicts.

- ## How It Works
The visualizer places queens row by row while checking:
- Column conflicts
- Left diagonal conflicts
- Right diagonal conflicts

If a conflict occurs, the algorithm backtracks and tries another position.
