# N-Queen Visualizer ♛

An interactive web-based visualization of the N-Queens problem using backtracking.

## 🚀 Features
- Dynamic board size (2–8)
- Step-by-step visualization
- Speed control
- Solution counter
- Clean UI with animations

## 🧠 Algorithm
Backtracking approach:
- Place queens column-wise
- Validate row, column, diagonal
- Backtrack on conflicts

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
